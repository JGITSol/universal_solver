## Badge Services

All badges are generated using:
- **GitHub Shields.io**: Most dynamic badges (issues, stars, etc.)
- **GitHub Actions**: CI/CD status badges
- **Local SVG**: Test coverage badge (generated by coverage tools)

## Maintaining Badges

- GitHub badges automatically update based on repository activity
- Test coverage badge is generated during CI runs
- All badge URLs use the repository path: `JGITSol/universal_solver`

## Future Badge Considerations

Additional badges that could be added when applicable:
- **PyPI Version**: When the package is published to PyPI
- **PyPI Downloads**: To show package download statistics
- **Documentation Status**: When hosted documentation is available (e.g., Read the Docs)
- **Code Climate**: For code quality metrics
- **Dependabot**: For dependency update status
- **Security Badges**: For vulnerability scanning results
