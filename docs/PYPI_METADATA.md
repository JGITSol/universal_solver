# PyPI Classifiers and Keywords Documentation

This document explains the classifiers and keywords added to `setup.py` for better discoverability on PyPI and other package indexes.

## PyPI Classifiers

PyPI classifiers help users find your package by categorizing it according to various attributes. Our project includes the following classifier categories:

### Development Status
- **Development Status :: 3 - Alpha**: Indicates the project is in alpha stage, functional but still under active development.

### Intended Audience
- **Intended Audience :: Developers**: For software developers
- **Intended Audience :: Science/Research**: For researchers and scientists
- **Intended Audience :: Education**: For educational purposes

### Topic
- **Topic :: Scientific/Engineering**: General scientific/engineering software
- **Topic :: Scientific/Engineering :: Mathematics**: Mathematical tools and libraries
- **Topic :: Scientific/Engineering :: Artificial Intelligence**: AI and machine learning
- **Topic :: Software Development :: Libraries :: Python Modules**: Python library

### License
- **License :: OSI Approved :: MIT License**: Open source under MIT license

### Operating System
- **Operating System :: OS Independent**: Works on any OS
- **Operating System :: Microsoft :: Windows**: Windows support
- **Operating System :: POSIX :: Linux**: Linux support
- **Operating System :: MacOS**: macOS support

### Programming Language
- **Programming Language :: Python :: 3**: Python 3 support
- **Programming Language :: Python :: 3.8**: Python 3.8 support
- **Programming Language :: Python :: 3.9**: Python 3.9 support
- **Programming Language :: Python :: 3.10**: Python 3.10 support
- **Programming Language :: Python :: 3.11**: Python 3.11 support
- **Programming Language :: Python :: 3.12**: Python 3.12 support
- **Programming Language :: Python :: 3 :: Only**: Python 3 only, no Python 2

### Environment
- **Environment :: Console**: Command-line application
- **Environment :: GPU**: GPU-accelerated computing support

### Framework
- **Framework :: Jupyter**: Jupyter notebook integration

### Natural Language
- **Natural Language :: English**: Documentation and interface in English

### Typing
- **Typing :: Typed**: Includes type hints

## Keywords

Keywords help users discover the package through search. Our project includes:

### Core Concepts
- `mathematics`: Core mathematical functionality
- `solver`: Problem-solving capabilities
- `symbolic-mathematics`: Symbolic computation
- `symbolic-regression`: Symbolic regression techniques

### AI/ML Keywords
- `ai`: Artificial intelligence
- `machine-learning`: Machine learning applications
- `deep-learning`: Deep learning integration
- `neural-networks`: Neural network models
- `ensemble-learning`: Ensemble methods

### Technologies
- `langchain`: LangChain integration
- `ollama`: Ollama support
- `pytorch`: PyTorch framework
- `sympy`: SymPy symbolic mathematics

### Specific Features
- `kan`: Kolmogorov-Arnold Networks
- `kolmogorov-arnold-networks`: Full name for KAN
- `benchmark`: Benchmarking capabilities
- `math-problem-solving`: Mathematical problem solving
- `gsm8k`: GSM8K dataset support
- `math-dataset`: Mathematical dataset support

## Project URLs

Added to setup.py for better navigation:

- **Bug Tracker**: Link to GitHub issues
- **Documentation**: Link to docs folder
- **Source Code**: Link to GitHub repository
- **CI/CD**: Link to GitHub Actions

## Benefits

These additions provide several benefits:

1. **Discoverability**: Users can find the package through PyPI search
2. **Filtering**: Users can filter packages by Python version, OS, etc.
3. **Credibility**: Shows the project is well-maintained and documented
4. **Navigation**: Easy access to important project resources
5. **SEO**: Improves search engine optimization for the project

## Maintenance

When updating the project:
- Update Development Status as the project matures (Beta, Production/Stable, etc.)
- Add new Python versions as they become supported
- Add new keywords if new features or technologies are integrated
- Keep classifiers accurate to maintain user trust
